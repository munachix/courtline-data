# courtline-data

Public NBA score data for the Courtline app, refreshed about every 5 minutes by
GitHub Actions and served through jsDelivr for networks where the main server
is unreachable. Contains only public game data. No keys, no personal data.

- `data` branch: `snapshot.json`, `allgames.json`, `outlooks.json`, `power.json`, `race.json`, `articles.json`, `leaderboard.json`
- CDN: `https://cdn.jsdelivr.net/gh/munachix/courtline-data@data/snapshot.json`
